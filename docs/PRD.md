## 1. 개요

### 1.1 배경
건설업 시공능력평가액은 공종(업종)별로 서로 다른 협회가 공시한다. 발주·입찰 실무에서 특정 업체의 공종별 평가액과 순위를 확인하려면 협회별 사이트를 각각 조회해야 하며, 협회마다 파일 포맷·컬럼 구성·금액 단위가 달라 직접 비교가 불가능하다.

### 1.2 목표
1. 6개 대분류(종합건설·전문건설·기계설비·소방설비·전기설비·정보통신)의 시공능력평가 데이터를 **하나의 표준 스키마로 정규화**한다.
2. 정규화된 전체 데이터(약 14.3만 건)를 내장한 **단일 HTML 조회기**를 제공한다. 서버·설치 없이 브라우저만으로 동작한다.
3. 매년 8월 2일 기준으로 재수집·재생성이 가능하도록 **수집 방법·변환 규칙·실행 스크립트를 코드와 문서로 보존**한다.

### 1.3 비목표
- 실시간 조회(협회 API 연동)는 하지 않는다. 연 1회 스냅샷 방식이다.
- 시공능력평가액 외 재무제표, 수주실적 등 추가 데이터 통합은 범위 밖이다.

## 4. KECA(전기설비) 크롤링 명세

> 2025년 수집 시 검증된 방법. 매년 재크롤링 전 §4.6 체크리스트를 먼저 확인한다.
> 참조 구현: `scripts/crawl_keca.py`

### 4.1 대상
- 모바일 회원사 검색: `https://m.keca.or.kr/service/service07.do?menuCd=4051`
- 목록 페이지(업체명·대표자·주소 일부·내부 license ID) + 상세 페이지(등록번호·시공능력평가액·지역/전국순위) **조합**으로 수집해야 한다. 목록만으로는 평가액을 얻을 수 없다.

### 4.2 요청 구조
| 구분 | 방식 | URL | 비고 |
|---|---|---|---|
| 초기 진입 | GET | `/service/service07.do?menuCd=4051` | 세션·CSRFToken 확보 |
| 목록 조회 | **POST** | `/service/service07.do` | `gubun=page` |
| 상세 조회 | **POST** | `/service/service07D.do` | `gubun=detail` |

- 폼의 원래 `method="get"`이지만 자바스크립트(`js_searchAction`)가 POST로 강제 변경한다. **GET으로 구현하면 안 된다.**
- hidden 필드: `menuCd`, `currentPageNo`, `license`, `gubun`, `CSRFToken` — CSRFToken은 세션과 함께 매 요청에 포함.

### 4.3 파라미터
- 목록: `menuCd=4051`, `currentPageNo=<페이지>`, `license=`(빈값), `gubun=page`, `searchSido`, `searchSigungu`, `searchGubun`(company/daepyo/licenNo), `searchText`, `CSRFToken`
- 상세: 위와 동일하되 `license=<내부 license ID>`, `gubun=detail`
- 상세 진입 키는 화면의 등록번호가 아니라 목록의 `onclick="js_detailAction('12720521')"`에 들어있는 **내부 license ID**다.

### 4.4 추출 데이터
- 목록: 상호(`<div class="name">[경남-00408] 125전기공사</div>` 형식), 대표자, 주소, license ID
- 상세: 등록번호, 등록일, 관할시도회, 상호, 대표자, 소재지, **시공능력평가액**(th 라벨 `시공능력<br/>평가액` 행의 td), 지역순위, 전국순위
- 순위·평가액에 문구·공백이 섞이므로 정규식으로 숫자만 추출. 원본 문자열과 정제 숫자를 **둘 다 저장**한다.
- 저장 컬럼: `license_id, 등록번호, 등록일, 관할시도회, 상호, 대표자, 소재지, 시공능력평가액_원문, 시공능력평가액, 지역순위, 전국순위`

### 4.5 규모·운영
- 2025년 기준 총 21,179건, 페이지당 10건 → 목록 약 2,118회 + 상세 약 21,179회 요청
- **중간 저장 필수**: `SAVE_INTERVAL` 페이지마다 중간 파일 저장 (`keca_시공능력평가액_중간_0100p.xlsx` 식 명명), 실패 license ID는 별도 파일로 기록해 부분 재수집

## 5. 표준 데이터 스키마

### 5.1 raw CSV 표준 헤더 (파이프라인 입력)
모든 소스는 아래 헤더의 UTF-8(BOM) CSV로 변환해 `raw/`에 둔다. 소스가 제공하지 않는 컬럼은 빈 값.

```
대분류,중분류,순위,상호,대표자,소재지,등록번호,시공능력평가액,공사실적평가액,경영평가액,기술능력평가액,신인도평가액,건설공사실적,기술자수
```

- **선택 컬럼 `사업자번호`**: 원본에 사업자등록번호(10자리)가 있는 소스는 표준 헤더 뒤에 `사업자번호` 컬럼을 추가할 수 있다. 파이프라인이 자동 인식한다 (`사업자번호` 또는 `사업자등록번호` 헤더 모두 허용).

### 5.2 정규화 레코드 (파이프라인 출력, HTML 내장 JSON)
| 필드 | 타입 | 원본 컬럼 | 설명 |
|---|---|---|---|
| `cat` | string | 대분류 | 종합건설/전문건설/기계설비/소방설비/전기설비/정보통신 |
| `sub` | string | 중분류 | 공종명 |
| `rank` | int | 순위 | 공종 내 시공능력평가액 순위 (§6.4) |
| `name` | string | 상호 | 업체명 |
| `rep` | string | 대표자 | 미제공 시 빈 문자열 |
| `addr` | string | 소재지 | 미제공 시 빈 문자열 |
| `reg` | string | 등록번호 | 건설업/공사업 등록번호, 문자열 보존 |
| `bizno` | string(선택) | 사업자번호 | **원본에 있을 때만 포함.** 하이픈 제거 10자리로 정규화 |
| `amt` | number | 시공능력평가액 | **백만원 통일** (§6.2) |

## 6. 정규화 규칙

구현: `scripts/normalize.py`

### 6.1 인코딩·파싱
- 입력 CSV는 `utf-8-sig`로 읽는다 (BOM 제거).
- 금액·숫자 필드: 콤마 제거 후 float 변환. 변환 실패 시 해당 행을 리포트에 기록하고 값은 결측 처리.
- `순위`: `1.0` 같은 float 표기는 int로 변환.
- `등록번호`: 문자열 보존. 단, `668.0`처럼 float 변환 흔적이 있으면 `.0` 접미사 제거.
- 문자열 필드는 `strip()` 후 저장, 결측은 빈 문자열.

### 6.2 금액 단위 통일 (→ 백만원)
| 소스 | 원본 단위 | 변환 |
|---|---|---|
| 종합건설, 전문건설, 기계설비 | 백만원 | 그대로 (÷1) |
| 소방설비, 전기설비, 정보통신 | 천원 | **÷1,000** |

### 6.3 사업자번호 (조건부)
- raw CSV에 `사업자번호`/`사업자등록번호` 컬럼이 있으면 하이픈·공백 제거 후 `bizno`로 포함. 10자리 숫자가 아니면 경고 리포트.
- 컬럼이 없는 소스는 `bizno` 필드 자체를 생성하지 않는다.
- **산출물 동작**: 내장 데이터에 `bizno`가 1건이라도 있으면 결과 테이블·CSV 내보내기에 '사업자번호' 컬럼이 자동 표시되고, 없으면 컬럼 자체가 나타나지 않는다. *(→ 원본 엑셀에 사업자번호 존재 여부 확인은 §11 미결사항)*

### 6.4 순위 정책
- 기본: 소스 제공 순위 사용 (`rank_policy: source`)
- **기계설비: 평가액 내림차순 재산정** (`rank_policy: recompute`) — 원본 순위가 가나다순 일련번호이기 때문 (§3.1)
- 검증: 모든 소스에 대해 "공종 내 평가액 최댓값 행의 순위 = 1" 여부를 확인하고, 불일치하면 경고 리포트 (다른 소스의 순위 오염 조기 감지)

### 6.5 중복 정책
- (대분류, 중분류, 상호) 단위로만 중복을 점검한다. 전문건설의 다공종 등록은 정상이므로 대분류 간 중복은 허용.

## 7. 데이터 품질 검증

`normalize.py`가 실행 시 자동 수행하고, 하나라도 실패하면 종료 코드 ≠ 0 (산출물 생성 중단).

| # | 검증 | 기준 |
|---|---|---|
| Q1 | 파일 존재·비어있지 않음 | 6개 raw 파일 모두 헤더+1행 이상. **빈 파일(2바이트)은 즉시 실패** |
| Q2 | 최소 행수 | 전년 대비 –20% 이상 감소 시 실패 (2025 기준값: §3 표) |
| Q3 | 필수 컬럼 | 대분류·중분류·순위·상호·시공능력평가액 결측률 1% 미만 |
| Q4 | 금액 범위 | 변환 후 amt가 0 초과, 공종 1위가 상식적 규모인지 (종합 1위 > 10조, 전기 1위 > 1조 등) — 단위 변환 누락 감지 |
| Q5 | 순위 정합성 | 공종 내 최대 amt 행의 rank = 1 |
| Q6 | 사업자번호 형식 | bizno 존재 시 10자리 숫자 비율 99% 이상 |

## 8. 산출물(HTML 조회기) 요구사항

단일 HTML 파일. 데이터 JSON 내장, 외부 요청 없음(오프라인 동작). 생성: `scripts/build_html.py`

### 8.1 기능 (v4 유지)
- **업체명 검색**: 최대 10개 동시 입력, 부분일치, 입력 순서별 색상 구분
- **공종 필터**: 중분류 다중 선택 최대 3개
- **예정가격 판정**: 예정가격(백만원) 입력 시 각 행에 초과(✓)/미달(✗) 표시
- **정렬**: 모든 컬럼 헤더 클릭 정렬 (토글)
- **행 제외**: 결과에서 개별 행 삭제(✕)
- **CSV 내보내기**: 현재 결과를 UTF-8 BOM CSV로 다운로드
- 결과 컬럼: #, 대분류, 공종(중분류), 업체명, 대표자, 소재지, 평가액(백만원), 공종내순위, 제외

### 8.2 v5 변경사항
1. **사업자번호 조건부 컬럼**: 데이터에 `bizno`가 존재하면 '소재지' 다음에 '사업자번호' 컬럼 자동 표시 + CSV 내보내기에도 포함. 없으면 완전 숨김
2. **업데이트 주기 표기**: 헤더에 "기준: {연도}년 공시 · 매년 8월 2일 갱신" 배지
3. **버그 수정**: v4 `doSearch()`의 상태바 문구 생성부가 미정의 변수 `cat`을 참조해 검색 후 상태바가 갱신되지 않던 문제(ReferenceError) 수정
4. 기계설비 순위가 재산정된 값으로 반영 (§6.4)
